## Scope

Smaller data files without a dedicated page:

- `credits/` — credits screen content.
- `arena/` — arena challenge definitions (waves, enemies, bonuses) —
  see [game: arena](../../engine/game/12-arena.md).
- `save-presets/` — new-game preset saves.
- `global-settings.json` — default options.
